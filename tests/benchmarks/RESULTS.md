# Benchmark results

Self-run, small benchmarks. They are not comparable to published leaderboard numbers (LongMemEval etc.). Two independent runs are reported:

- **Scenario 1**: structural retrieval without an LLM (`tests/benchmarks/structural/`, raw results in `results_structural.json` / `results_structural.md`).
- **Local-LLM run**: end-to-end QA with Ollama `qwen2.5:0.5b-instruct` and `qwen2.5:1.5b-instruct` (`tests/benchmarks/llm/`, dataset `workshop-micro` v2, seed 1729, temperature 0, k=4, 48 questions, 3 runs per mode except Mem0 with 1 run).

## Summary

| system | LLM-run accuracy (qwen2.5 1.5B) | avg prompt tokens per question (LLM run) | Scenario 1: 2-hop chains, 10k noise, all gold facts within 1000 tokens |
|---|---|---|---|
| no memory | 0.167 | 103 (prompt overhead only) | n/a |
| plain RAG | 0.424 | 145 | 0.0 (0/8) |
| graph `search` (default, outdated hidden) | 0.514 | 148 | 0.0 (0/8) |
| graph `search` with `include_outdated` | 0.368 | 147 | n/a |
| graph `recall_context` depth 2 | not run | n/a | 0.875 (7/8), median 137 tokens to all gold |
| Mem0 | 0.646, **inflated, not comparable (see caveats)** | 683 | not run |
| Graphiti | **failed, no result** | n/a | not run |

Prompt tokens are the model prompt size reported by Ollama, averaged over all questions. Scenario 1 tokens use a regex proxy tokenizer (see below).

## Caveats

### Mem0 (0.646 on 1.5B) is inflated and not comparable

With the weak 1.5B model, Mem0's LLM fact extraction failed, so Mem0 stored the raw episodes instead of extracted facts. Its retrieved context was therefore much larger: about 683 prompt tokens per question versus about 147 for the graph (roughly 4.5x more context). The higher accuracy comes from feeding more raw text, not from better memory. Its recall@4 of 0 is an artifact of the harness, which matches gold facts by text and cannot match raw episodes; it does not mean Mem0 retrieved nothing. On 0.5B Mem0 scored 0.188 (1 run).

### Graphiti could not complete

Graphiti is reported as a failure. First it failed to authenticate against FalkorDB; after that was fixed, ingestion stalled on malformed JSON produced by the weak models. Only 2 of 12 episodes were ingested with 0.5B and 1 of 12 with 1.5B, and the runs were stopped. No accuracy is reported.

### Local-LLM run

- Contradiction questions scored 0.00 for every mode.
- The graph's gain over RAG comes mostly from hiding outdated facts (updated_fact 0.83 vs 0.29 on 1.5B). With `include_outdated` the graph drops to 0.368. Relations between facts are not used in this run (`search` only).
- 0.5B results: none 0.049, RAG 0.507, graph 0.500, graph+outdated 0.507, Mem0 0.188.

### Scenario 1 limits

- 3-hop chains fail for every system at 1k and 10k noise (all@1000 = 0.0). In `recall_context` the 5 seeds include noise facts with the same surname, and the multi-source traversal spends the 50-node cap (`SUBGRAPH_MAX_NODES_LIMIT`) on hops 1-2 of all seeds before hop 3 of the right one. depth=3 does not help.
- The token counter is a regex proxy (`\w+|[^\w\s]`), not a model tokenizer.
- Small dataset: 107 core facts, 40 questions (8 per chain type), plus 10,000 generated noise facts. Synthetic, template-based, self-run.
- Controls, aggregates and current-value questions are 1.0 for all systems; the systems differ only on chains and stale facts.
- Stale facts within 1000 tokens: RAG 1.0, graph 0.0.

## Scenario 1 details

Generated by `structural/generate.py` (seed 1729, no LLM). Systems: `rag` = cosine similarity over all fact sentences with the server's ONNX embeddings (outdated included); `graph_search` = `search(node_types=["Fact"], limit=100)`; `graph_recall_dN` = `recall_context(depth=N, limit=5, max_nodes=50)`. Metric all@N: all gold facts of a question appear in the first N context tokens. Backend FalkorDB.

all@1000 on chain questions:

| system | 2-hop, noise 0 | 2-hop, 1k | 2-hop, 10k | 3-hop, noise 0 | 3-hop, 1k | 3-hop, 10k |
|---|---|---|---|---|---|---|
| rag | 1.0 | 0.5 | 0.0 | 1.0 | 0.125 | 0.0 |
| graph_search | 1.0 | 0.5 | 0.0 | 1.0 | 0.125 | 0.0 |
| graph_recall_d2 | 1.0 | 1.0 | 0.875 | 0.125 | 0.0 | 0.0 |
| graph_recall_d3 | 1.0 | 1.0 | 0.875 | 0.25 | 0.0 | 0.0 |

Latency at 10k noise (median per query): rag ~75 ms, graph_search ~107 ms, recall_context d2 ~417 ms, d3 ~504 ms.

Reproduce: `GRAPH_BACKEND=falkordb python tests/benchmarks/structural/run.py`, then `report.py`; opt-in test `STRUCTURAL_BENCH=1 pytest -m structural_bench`.
